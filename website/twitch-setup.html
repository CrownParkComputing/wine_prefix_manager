Setup Guide

Follow these simple steps to enable IGDB integration in Wine Prefix Manager

1

Create Twitch Developer Account

Visit the Twitch Developer Console and create a new application to get your API credentials.

Open Twitch Dev Console

What you'll need to do:

  • Log in with your Twitch account
  • Click "Register Your Application"
  • Fill in the application details
  • Set OAuth Redirect URL to: http://localhost
  • Select "Other" as category
2

Get Your Client ID and Secret

After creating your application, copy your Client ID and generate a Client Secret.

Keep these credentials secure. You'll enter them in Wine Prefix Manager settings.
3

Configure Wine Prefix Manager

Open Wine Prefix Manager settings and enter your Twitch IGDB credentials.

Settings - IGDB Integration

In the app:

  1. Go to Settings → IGDB Integration
  2. Toggle "Enable IGDB Integration" to ON
  3. Enter your Client ID and Client Secret
  4. Click "Test Connection" to verify
  5. Save your settings
4

Enjoy Enhanced Game Library

Your games will now automatically fetch rich metadata from IGDB when detected or added.

Frequently Asked Questions

Is IGDB integration free?

Yes! IGDB provides a free tier that's perfect for personal use. You get 4 requests per second and 10,000 requests per month, which is more than enough for most users.

What data does IGDB provide?

IGDB provides comprehensive game information including cover art, screenshots, trailers, release dates, genres, platforms, developer/publisher info, ratings, and detailed descriptions.

How accurate is the game detection?

Wine Prefix Manager uses intelligent matching algorithms to identify games by their executable names, folder structure, and metadata. You can also manually search and link games if automatic detection fails.

Can I use this offline?

Once game data is fetched, it's cached locally for offline use. However, you'll need an internet connection for initial data fetching and updates.

Is my data secure?

Your Twitch credentials are stored locally and encrypted. Wine Prefix Manager only communicates with official Twitch/IGDB APIs and doesn't send your personal data anywhere else.

What if a game isn't found?

You can manually search IGDB within the app, or choose to use custom artwork and information. IGDB has a vast database, but some obscure or very new games might not be available.
